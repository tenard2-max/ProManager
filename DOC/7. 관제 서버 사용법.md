# Central-Agent Orchestration — 관제 서버 사용법

**플랫폼:** Central-Agent Orchestration (AI 관제 에이전트)  
**작성일:** 2026-11-18 · **버전:** v1.0

---

## 1. 메인 콘솔을 띄우려면?

**예. `run_server.bat`만 실행하면 됩니다.**

| 순서 | 동작 |
|------|------|
| 1 | `D:\Cursor\ProjManager\monitor_agent\run_server.bat` 더블클릭 (또는 터미널에서 실행) |
| 2 | 검은 콘솔 창이 뜨며 서버가 기동됨 |
| 3 | 약 2초 후 브라우저가 `http://127.0.0.1:18765/` 로 자동 실행 |
| 4 | 관제 UI(대시보드)가 메인 콘솔 화면 |

> **주의:** 예전 포트 `8765`는 XFS 시뮬레이터 등 **다른 로컬 서비스**가 쓰는 경우가 있습니다.  
> 관제는 **`18765`** 전용입니다. `8765`를 열면 “프로젝트 로딩 중…”처럼 API가 안 맞을 수 있습니다.

- **콘솔 창을 닫거나 Ctrl+C** 하면 서버가 종료되고 UI도 끊깁니다.
- 콘솔은 그대로 두고, 작업은 **브라우저 UI**에서 합니다.

## 2. 배치 파일 역할

경로: `D:\Cursor\ProjManager\monitor_agent\`

| 파일 | 용도 | 언제 쓰나 |
|------|------|-----------|
| **`run_server.bat`** | **메인 관제 서버 + UI 기동** | 평소 관제할 때 (운영) |
| **`run_tests.bat`** | 자동 테스트(`pytest`)만 실행 | 코드 수정 후 검증할 때 (개발) |

### 2.1 `run_server.bat`가 하는 일

1. 작업 폴더를 `monitor_agent`로 이동
2. `pip install -r requirements.txt` 로 의존성 확인
3. 포트 **18765**를 쓰는 기존 관제 프로세스가 있으면 종료 (중복 기동 방지)
4. 브라우저를 `http://127.0.0.1:18765/` 로 염
5. `python -m app.main` 으로 FastAPI 관제 서버 실행

### 2.2 `run_tests.bat`가 하는 일

1. 의존성 설치 확인
2. `pytest -q` 로 단위·통합 테스트 실행
3. **UI/서버는 띄우지 않음**

> 테스트 bat ≠ 관제 콘솔. 메인 화면이 필요하면 반드시 `run_server.bat`.

## 5. 에이전트(Cursor / 그록) 연동 요약

관제만 켜 둔 상태에서는 에이전트가 **OFFLINE**일 수 있습니다.  
에이전트가 HEARTBEAT·메시지를 보내야 ONLINE이 됩니다.

| 주체 | 전달 문서 | 주요 동작 |
|------|-----------|-----------|
| Cursor IDE | `DOC/6. 요구사항.MD` | SPEC_RESET, STATUS_UPDATE, HEARTBEAT |
| 그록 봇 | `DOC/6. 요구사항 - 봇.MD` | QA_RESULT, HEARTBEAT |
| 발주자 | 브라우저 UI | 명령·최종 승인 |

참고 CLI:

```text
cd D:\Cursor\ProjManager\monitor_agent
python tools/agent_client.py heartbeat --agent cursor
python tools/agent_client.py status --req REQ_001 --progress 60
python tools/agent_client.py qa --req REQ_001 --qa-status PASSED --qa-score 90
```

## 6. 자주 있는 증상

| 증상 | 원인 | 조치 |
|------|------|------|
| 포트 18765 오류 | 이전 관제 서버가 아직 실행 중 | `run_server.bat`이 자동 종료 시도. 안 되면 해당 PID 종료 후 재실행 |
| **프로젝트 로딩 중… / API 404** | **브라우저가 8765(다른 앱)에 접속** | 주소가 **`http://127.0.0.1:18765/`** 인지 확인. `run_server.bat` 재실행 |
| UI가 안 보임 | 서버 미기동 또는 브라우저만 연 상태 | `run_server.bat` 실행 후 콘솔 유지 |
| 에이전트 OFFLINE | HEARTBEAT 없음 | Cursor/그록이 관제에 연결·심박 전송 |
| 사용량 %가 안 맞음 | Cursor 미로그인 또는 API 동기화 실패 | Cursor 로그인 확인, UI에 「Cursor 자동 동기화」 표시 여부 확인 |
