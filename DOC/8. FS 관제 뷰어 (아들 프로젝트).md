# FS 관제 뷰어 (아들 프로젝트)

**작성일:** 2026-11-18 · **버전:** v1.0  
**경로:** `D:\Cursor\ProjManager\monitor_fs_ui`

## 목적

기존 FastAPI 관제(`monitor_agent`)는 그대로 두고,  
**File System Access API**로 로컬 INI를 5초마다 읽어 보여주는 **정적 UI 아들 프로젝트**.

## 실행

| 구분 | 방법 | URL |
|------|------|-----|
| 아들 뷰어 | `monitor_fs_ui\open_ui.bat` | http://127.0.0.1:18766/ |
| 부모 관제 | `monitor_agent\run_server.bat` | http://127.0.0.1:18765/ |

1. Chrome/Edge에서 뷰어 열기  
2. **data 폴더 선택** → `monitor_agent\data`  
3. 에이전트가 INI를 바꾸면 약 5초 내 화면 갱신  

## 유지 조건

- 부모 `monitor_agent`의 서버·스크립트·bat **기능 변경 없이 유지**
- 아들은 읽기 전용 뷰어 (명령·메시지 서버 대체 아님)

## 브라우저 제약

- Secure Context 필요 → `open_ui.bat`(localhost) 사용  
- `file://` 로 열면 File System Access API 사용 불가  
- 최초(또는 권한 만료 시) 폴더 선택 필요 · 이후 IndexedDB에 핸들 저장
