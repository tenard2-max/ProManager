# FS 관제 뷰어 / GitHub Pages 모니터링 콘솔

**작성일:** 2026-11-18 · **버전:** v1.1  
**공개 URL:** https://tenard2-max.github.io/ProManager/  
**로컬 경로:** `monitor_fs_ui/` (백업) · 배포 원본: 저장소 루트 `docs/`

## 목적

기존 FastAPI 관제(`monitor_agent`)의 **메시지·명령 API는 유지**하고,  
발주자용 **모니터링 UI는 GitHub Pages 정적 콘솔**을 기본으로 사용한다.  
File System Access API로 로컬 프로젝트 `docs/` INI를 5초마다 읽어 보여준다.

## 실행

| 구분 | 방법 | URL |
|------|------|-----|
| **GitHub Pages (기본)** | 브라우저에서 열기 | https://tenard2-max.github.io/ProManager/ |
| 로컬 백업 뷰어 | `monitor_fs_ui\open_ui.bat` | http://127.0.0.1:18766/ |
| 부모 관제 API | `monitor_agent\run_server.bat` | http://127.0.0.1:18765/ |

1. Chrome/Edge에서 콘솔 열기  
2. **docs 폴더 선택** → 예: `D:\Cursor\XFS\docs`  
3. 에이전트가 INI를 바꾸면 약 5초 내 화면 갱신  

## 유지 조건

- 부모 `monitor_agent`의 서버·스크립트·bat **기능 변경 없이 유지**
- 정적 콘솔은 읽기 전용 뷰어 (명령·메시지 서버 대체 아님)
- GitHub Pages 배포 루트는 저장소 `docs/` (소스와 `monitor_fs_ui/` 동기화)

## 브라우저 제약

- Secure Context 필요 → GitHub Pages(HTTPS) 또는 `open_ui.bat`(localhost)  
- `file://` 로 열면 File System Access API 사용 불가  
- 최초(또는 권한 만료 시) 폴더 선택 필요 · 이후 IndexedDB에 핸들 저장
